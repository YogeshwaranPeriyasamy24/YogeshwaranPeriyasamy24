# RAG Document Q&A

A portfolio project for learning and demonstrating Retrieval-Augmented Generation (RAG).

## Planned architecture

```text
Documents
   ↓
Text Extraction
   ↓
Chunking
   ↓
Embeddings
   ↓
Vector Store
   ↓
User Question
   ↓
Similarity Search
   ↓
Relevant Context
   ↓
LLM
   ↓
Grounded Answer
```

## Learning goals

- Understand embeddings and semantic search
- Build a document ingestion pipeline
- Store and retrieve relevant chunks
- Provide context to an LLM before generating an answer
- Explore RAG evaluation and hallucination reduction

## Planned technologies

- Python
- LLM API
- Embeddings
- Vector database
- RAG pipeline

> This is a learning/portfolio project. Implementation will be added as the AI learning journey progresses.
