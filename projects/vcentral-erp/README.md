# VCentral — Enterprise Resource Planning (ERP)

Enterprise ERP application work covering business modules, integrations, workflows and database logic.

## Key areas

- CBR, Project, SOWPO, Customer and Timesheet modules
- UI screens, workflows and business logic
- REST API integration with SAP via Infogram
- Holiday and Time-Off data exchange
- Complex SQL query development and optimization
- Data migration, validation and reconciliation
- Scheduler jobs and BPT background processes

## Technologies

- OutSystems 11 / ODC
- Reactive Web
- REST APIs
- SAP Integration
- SQL Server / SSMS
- BPT / Timers

> This repository contains a portfolio-level description of the project. Client-confidential source code and data are not included.
