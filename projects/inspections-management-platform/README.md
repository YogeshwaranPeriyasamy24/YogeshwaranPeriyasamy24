# Inspections Management Platform

Enterprise inspection and case-management solution developed with OutSystems.

## Key capabilities

- Dynamic checklist templates
- End-to-end approval workflows
- SLA-driven case management
- Automated status tracking and escalation
- Multi-tenant application architecture
- Offline mobile data capture and synchronization

## Technologies

- OutSystems 11 / ODC
- Reactive Web
- Mobile
- BPT / Workflow Automation
- SQL

> This repository contains a portfolio-level description of the project. Client-confidential source code and data are not included.
